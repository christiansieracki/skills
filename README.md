# skills

Claude-Skills von Christian Sieracki, als Plugin-Marketplace.

## Einrichten

```
/plugin marketplace add christiansieracki/skills
/plugin install volleyball@christiansieracki-skills
```

## Aktualisieren

```
/plugin marketplace update
/plugin update volleyball@christiansieracki-skills
```

## Plugins

| Plugin | Inhalt |
|---|---|
| [volleyball](plugins/volleyball) | Saisonplanung, Trainingsdesign und Übungsimport für Volleyballteams |
