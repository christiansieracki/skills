# Schwerpunkte

Die verbindliche Liste. Saisonplan, Mesozyklen, Trainingspläne und Übungskarten
benutzen **nur** die Kennungen aus der linken Spalte. Nur so findet die Suche
zu einem Mesozyklus-Schwerpunkt auch die passenden Übungen.

Startfassung. Sie deckt den üblichen Erwachsenen- und Jugendbetrieb ab und
wird von hier aus für euren Verein erweitert.

## Wie die Liste wächst

Ein neuer Schwerpunkt wird hier eingetragen, bevor er in einem Plan oder auf
einer Karte auftaucht. Ein Skill darf einen vorschlagen, eintragen tut ihn ein
Mensch. Umbenennen bitte nie ohne Suchen und Ersetzen über alle Dateien, sonst
zeigen alte Karten ins Leere.

## Inhaltliche Schwerpunkte

Das ist das, was man trainieren kann. Nur diese Kennungen dürfen im Feld
`schwerpunkt:` einer Übungskarte stehen.

| Kennung | Klartext |
|---|---|
| `ballkontrolle` | Sauberer Kontakt in Bagger und Pritschen, ohne Spielsituation |
| `technik-reaktivierung` | Grundtechniken nach einer Pause auffrischen |
| `annahme` | Annahme als Technikelement |
| `zuspiel` | Zuspiel als Technikelement |
| `abwehr` | Feldabwehr |
| `aufschlag` | Aufschlag, von unten bis Sprungaufschlag |
| `angriffsaufbau` | Die Kette Annahme, Zuspiel, Angriff |
| `angriffsvarianten` | Verschiedene Angriffsoptionen und ihr Timing |
| `block-abstimmung` | Einer- und Doppelblock, Absprache am Netz |
| `annahme-abwehr-grundordnung` | Riegelformen und Laufwege, systemunabhängig |
| `annahme-abwehr-wettkampfdruck` | Dasselbe unter Druck, mit Wertung oder Gegner |
| `sideout-sicherheit` | Den eigenen Aufschlagball sicher zurückgewinnen |
| `sideout-konstanz` | Sideout über eine lange Serie halten |
| `laufwege-rotation` | Positionen, Rotation, Wechsel zwischen 5-1, 6-2 und situativ |
| `wettkampfhaerte` | Spielformen mit Wettkampfcharakter, Punkte und Konsequenz |
| `athletische-basis` | Stabilisation, Rumpf, allgemeine Belastbarkeit |
| `sprungkraftaufbau` | Sprungkraft und Landetechnik, kontrolliert aufgebaut |
| `koordination` | Koordination mit und ohne Ball |
| `teambuilding` | Zusammenhalt, Kommunikation, gemeinsames Arbeiten |

## Steuerungsschwerpunkte

Die gibt es nur auf Saison- und Mesozyklus-Ebene. Dazu gehören keine Übungen,
deshalb tauchen sie auf keiner Karte auf.

| Kennung | Klartext |
|---|---|
| `standortbestimmung` | Technik-Checks und Tests, um den Ausgangspunkt zu kennen |
| `belastungssteuerung` | Volumen und Frische über einen Trainingsblock steuern |
| `auswertung-hinrunde` | Auswertung der ersten Saisonhälfte |
| `gegneranalyse` | Gegner beobachten und aufbereiten |
| `gegneranpassung` | Die eigene Vorbereitung auf einen konkreten Gegner ausrichten |
| `saisonrueckblick` | Rückblick und Input für die nächste Saison |
