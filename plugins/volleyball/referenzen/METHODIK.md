# Methodik: Periodisierung auf Makro-/Mesoebene

## Grundprinzip

Drei Ebenen, jede leitet sich aus der übergeordneten ab:
- **Makrozyklus** = eine Saison (hier: ~9-10 Monate) — dieser Skill
- **Mesozyklus** = Block von 3-6 Wochen mit klarem Schwerpunkt — dieser Skill
- **Mikrozyklus/Einzeltraining** = einzelne Einheit — companion-Skill `volleyball-trainingsdesign`

## Saisonphasen (Makrozyklus)

1. **Allgemeine Vorbereitungsperiode** (~4-6 Wochen, meist Aug/Sept): Grundlagenausdauer, allgemeine Athletik, Technik-Basics auffrischen, Teambuilding, Standortbestimmung.
2. **Spezielle Vorbereitungsperiode** (~2-4 Wochen): volleyballspezifische Athletik, Systeme/Formationen festigen, erste Testspiele.
3. **Wettkampfperiode** (Hauptteil, ca. Oktober-März/April): im Rhythmus des Spielplans; Mesozyklen wechseln den Fokus; um wichtige Spiele/Pokalrunden herum Belastung senken.
4. **Übergangsperiode** (Saisonende, ~4-6 Wochen): aktive Erholung, geringe Belastung, Saisonrückblick als Input für den nächsten Makrozyklus.

## Mesozyklus-Logik

- Genau einen, maximal zwei klare Schwerpunkte pro Block — keine Sammelsurium-Blöcke.
- Progression innerhalb des Blocks: vom isolierten Element → zur Kombination → zur Wettkampfsituation.
- Belastung i.d.R. 2-3 Wochen aufbauend, dann 1 Woche reduziert; in der Wettkampfperiode an Spieltermine anpassen.
- Am Blockende: kurze Standortbestimmung (Spielbeobachtung, ggf. Test) → fließt in den Fokus des nächsten Blocks ein.
- Die konkrete Feinsteuerung innerhalb einer Trainingswoche (Erwärmung, Übungsauswahl, Tagesbelastung) liegt beim companion-Skill `volleyball-trainingsdesign`.

## Übertragung auf mehrere Teams / Levels

- Ambitionierte Erwachsenenteams: höhere Trainingsfrequenz möglich (3-4x/Woche + Spiel), mehr taktische Komplexität, expliziter Fokus auf Wettkampfdruck-Situationen.
- Andere Levels (Jugend, Freizeit): gleiche Struktur, nur Parameter anpassen (Frequenz, Komplexität, Volumen). Deshalb pro Team ein eigenes `team-profil.md`, während die Übungsbibliothek geteilt bleibt.

## Grundlage

Basiert auf etablierten Prinzipien der Trainingsperiodisierung (klassische und Block-Periodisierung), angewandt auf volleyballtypische Saisonstrukturen im deutschen Amateur-/ambitionierten Bereich. Saisontermine/Ligarhythmus im Zweifel beim zuständigen Verband recherchieren, da sie sich von Saison zu Saison verschieben.
